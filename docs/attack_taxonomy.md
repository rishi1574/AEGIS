# AEGIS Attack Taxonomy

1. **Synthetic ID Bust-out:** Long term trust building followed by massive credit extraction.
2. **Deepfake ATO:** Using GenAI voice/video to bypass biometric authentication.
3. **Transaction Fuzzing:** RL agents making micro-adjustments to amounts to stay below detection thresholds.
4. **Vishing:** Hyper-personalized voice phishing.
5. **Pig Butchering:** Long-term relationship scams leading to crypto investments.
6. **Digital Arrest:** Fake law enforcement extorting immediate high-value transfers.
7. **API Exploit:** Machine-speed attacks against payment gateways.
8. **Merchant Collusion:** Synthetic merchants passing funds to mules.
9. **Agentic Hijack:** Prompt injecting AI shopping assistants.
10. **Model Poisoning:** Slowly changing legitimate behavior to degrade Blue Team models.
11. **Supply Chain BEC:** GenAI-generated fake invoices mimicking vendors.
12. **Adversarial Document:** Forged KYC documents.
13. **Surrogate Evasion:** Training a shadow neural network to compute FGSM gradients against the Blue Team.
14. **MISLEAD SHAP Evasion:** Tricking tree-based explainers by forcing high-importance features to zero.
15. **Tabular Epsilon Attack:** Constrained optimization finding the exact epsilon perturbation boundary.
16. **CTGAN Mimicry:** Using Conditional Tabular GANs to perfectly match legitimate covariant distributions.
17. **Label Poisoning:** Generating borderline transactions designed to be misclassified, poisoning the retraining loop.
18. **Concept Drift:** Mathematically shifting time-of-day distributions to induce Covariant Shift.
19. **Graph Poisoning:** Sybil nodes inflating PageRank via micro-transactions before a bust-out.
20. **Temporal Fuzzing:** Evading LSTM anomaly detection using mathematically inverted Poisson distributions.
21. **MARL Collusion:** Proximal Policy Optimization across multiple agents minimizing a global shared risk score.
22. **Boundary Probing:** Probing the 0.49 probability margin to map the exact geometric shape of the decision boundary.
23. **Backdoor Injection:** Embedding tabular trigger patterns (e.g., exactly ₹404.04) that the model learns to ignore.
24. **NLP Payload Evasion:** Optimizing semantic transaction notes via LLM to bypass text-based risk scoring.
25. **Ensemble Evasion:** Exploiting linear Meta-Learner weights by appearing risky to one base model but safe to the others.
